# fake-profile-detection-neural-network
Detecting fake profiles on social networks using ANN - Python, TensorFlow, Keras

A machine learning system that detects fake profiles across 
online social networks using Artificial Neural Networks (ANN).

---

## 🔍 About The Project

Online social networks are flooded with fake accounts used 
for spam, fraud, identity theft, and cyberbullying. This 
system automatically detects whether a social media profile 
is fake or genuine using a trained ANN model.

---

## 🛠️ Tech Stack

- Python 3.7
- TensorFlow / Keras
- NumPy
- Pandas
- Matplotlib
- Scikit-learn

---

## ⚙️ How It Works

1. Upload social network profiles dataset
2. Preprocess data — remove missing values
3. Split into 80% training and 20% testing
4. Train ANN model for 200 epochs
5. Plot accuracy and loss graph
6. Predict whether a profile is Fake or Genuine
